# Ransel Design

Сайт аренды спецтехники. [Открыть сайт](https://nuralikuzhagaliev.github.io/Ransel/).

## Возможности

- Русский, английский и казахский языки. Русский открывается по умолчанию при каждой загрузке.
- Светлая и тёмная темы с сохранением выбора.
- Каталог семи машин, фильтры по видам работ и подробные характеристики.
- Формирование заявки в WhatsApp и ссылки для звонка.
- Адаптивная верстка и поддержка уменьшенного движения.

## Размещение и обновление

Сайт работает без сборки и серверных зависимостей. GitHub Pages публикует корень ветки `main`. Изменения в этой ветке обновляют сайт автоматически.

Для локального просмотра откройте `index.html` или запустите любой статический HTTP-сервер в корне репозитория.

Тексты переводов находятся в `i18n.js`, характеристики техники — в `app.js`, стили — в `styles.css` и `language.css`.

## Материалы

Изображения каталога и характеристики взяты из коммерческого предложения Ransel Design. Фоны первого экрана — визуализация. Стоимость, наличие и комплектация техники уточняются при обращении.

Локальный шрифт Noto Sans используется для казахского языка. Его лицензия включена в `assets/noto-sans-license.txt`.
